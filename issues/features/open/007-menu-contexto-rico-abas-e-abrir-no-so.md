# FEAT-007 — Menu de Contexto Rico no Fundo das Abas e Abrir Arquivo no SO

- **Status:** Open
- **Prioridade:** Médio | **Área:** `slices/media`, `slices/pptx`

## Descrição
- Ao clicar com o botão direito no espaço vazio de qualquer aba (`Imagens`, `Vídeos`, `Áudio`, `Arquivos`), exibir menu de contexto com:
  - **Nova Pasta (`+ Pasta`)**
  - **Abrir Pasta Local no Explorador do SO**
  - **Importar Arquivos**
  - **Reescanear Diretório**
- Ao clicar com o botão direito em um arquivo específico, incluir **Abrir Local do Arquivo no Explorador do SO**.
