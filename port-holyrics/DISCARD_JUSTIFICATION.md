# Auditoria Analítica de Arquivos Pendentes (Justificativas)

Dos arquivos Java originais, analisamos o que falta ser portado e justificamos a exclusão ou fusão do que era 'lixo' de arquitetura legada.

## 1. Arquitetura Swing Descartada / Mesclada no React (Justificada) 🗑️
> **Justificativa:** O Java Swing exige dezenas de arquivos dedicados para tratar cliques (`MouseAdapter`), renderização de células de tabelas (`ListCellRenderer`), e listeners de teclado/texto. No React, isso não existe como arquivo isolado: usamos funções aninhadas no próprio componente (`onClick`, `onChange`, `.map()`). Portanto, estes arquivos **não terão** um `.ts` isolado, pois sua lógica já foi ou será absorvida pelos componentes React nativos.

## 2. Bibliotecas de Terceiros e APIs Obsoletas (Descartadas) 🚫
> **Justificativa:** Códigos dedicados a atualização do executável Java (`javaupdate`), serialização nativa de Objetos Java (`lgsaveopen`) ou scripts antigos em PHP não fazem sentido no ecossistema web/TS. Atualizações serão feitas pelo Electron/Tauri; Serialização será feita via `JSON.parse()`. A API do Vagalume, se ainda viva, será consumida nativamente com um simples `fetch()` web (sem necessidade de DTOs nativos gigantes).
