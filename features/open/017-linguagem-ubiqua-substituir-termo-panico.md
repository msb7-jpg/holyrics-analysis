# FEAT-017 — Linguagem Ubíqua: Substituir o Termo "Pânico" por Controles de Saída

- **Status:** Open
- **Prioridade:** Médio | **Área:** `packages/core`, `slices/navigation`, `.agents/skills/lumen-domain`

## Descrição
Substituir na linguagem ubíqua do sistema todas as referências a `panic` / `PanicToolbar` / "Controles de Pânico" (código, contratos, UI e documentação) por um termo que reflita o controle real sobre o que está sendo projetado na tela (ex.: `OutputControls` / `Controles de Saída` para Blackout, Ocultar Letra e Congelar).
