Ajuda

Painel de ajuda do programa Holyrics.


Principais Funcionalidades
Letras de música
Salve a letra das músicas e utilize temas personalizados para exibição;
Exiba o texto todo em maiúsculo sem alterar a letra da música.
Rapidez, organização e praticidade
Encontre as músicas salvas rapidamente;
Separe as letras de diferentes grupos ou cantores utilizando perfis.
Pesquisa de letras na Web e também off-line
Pesquise e adicione uma música rapidamente utilizando as pesquisas disponíveis;
Banco de dados off-line com mais de 14 mil músicas.
Temas personalizados
Crie diversos Temas e utilize em qualquer letra.
Plano de fundo animado
Utilize os vídeos disponíveis para criar Temas com plano de fundo animado.
Histórico
Guarde a hora e a data de cada música tocada.
Lista de reprodução
Agende as músicas que serão tocadas em cada culto.
Escala dos integrantes
Cadastre os integrantes do grupo no sistema e crie a escala para os cultos.
Relatório
Veja o relatório das músicas mais tocadas, das músicas agendadas e dos integrantes escalados.
Acesso e controle pelo celular
Acesse os dados do programa e controle apresentações pelo celular através do aplicativo Holyrics.
